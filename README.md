# AI-Powered Code Review Assistant

## Overview

AI-Powered Code Review Assistant is a web application that analyzes source code for security vulnerabilities using Semgrep and AI. It detects common OWASP vulnerabilities, explains security issues in simple language, recommends secure coding practices, and generates professional PDF reports.

## Technology Stack

- React.js
- Tailwind CSS
- Node.js
- Express.js
- MongoDB Atlas
- Semgrep
- OpenAI API
- JWT Authentication

## Features

- User Authentication
- Upload ZIP Project
- Paste Source Code
- Automated Security Scan
- AI-Based Vulnerability Explanation
- Secure Code Suggestions
- Dashboard with Statistics
- PDF Report Generation
- Scan History
- Admin Panel
